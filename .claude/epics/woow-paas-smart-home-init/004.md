# Task: Config Flow 實作（OAuth2 + 多步驟選擇）

## Description
實作 `config_flow.py`，繼承 HA 的 `AbstractOAuth2FlowHandler` 完成 OAuth2 授權，接著透過 API Client 提供 workspace 選擇和 smart home 選擇的多步驟 config flow。最後取得 tunnel token 並建立 config entry。

## Acceptance Criteria
- [ ] `ConfigFlow` 繼承 `AbstractOAuth2FlowHandler`
- [ ] Step 1: OAuth2 授權（由 HA framework 自動處理 authorize → token exchange）
- [ ] Step 2: `async_step_select_workspace` — 呼叫 API 列出 workspaces，顯示下拉選單
- [ ] Step 3: `async_step_select_home` — 呼叫 API 列出 homes，顯示下拉選單
- [ ] 完成後呼叫 `get_tunnel_token(home_id)` 取得 tunnel_token, tunnel_id, subdomain
- [ ] Config entry data 儲存: OAuth2 token data + workspace_id + home_id + tunnel_token + subdomain
- [ ] 錯誤處理: API 失敗顯示 error message，使用者可重試
- [ ] 若 workspace 只有一個，自動跳過選擇步驟
- [ ] 若 home 只有一個，自動跳過選擇步驟

## Technical Details
- `AbstractOAuth2FlowHandler` 提供 `async_step_user` 和 `async_oauth_create_entry`
- 在 `async_oauth_create_entry` 之前插入 workspace/home 選擇步驟
- 使用 `self.hass` + OAuth2Session 建立臨時 ApiClient 進行 API 呼叫
- Config entry title 使用 smart home name
- `strings.json` 需對應所有步驟的 UI 文字
