# Task: OAuth2 Application Credentials 設定

## Description
實作 `application_credentials.py`，讓 HA 透過內建的 Application Credentials 機制管理 woow-paas-platform 的 OAuth2 client_id 和 client_secret。定義 OAuth2 authorize 和 token endpoint URL。

## Acceptance Criteria
- [ ] `application_credentials.py` 實作 `async_get_auth_implementation` 函式
- [ ] 正確設定 authorize URL: `{BASE_URL}/oauth2/authorize`
- [ ] 正確設定 token URL: `{BASE_URL}/oauth2/token`
- [ ] `manifest.json` 的 `dependencies` 包含 `["application_credentials"]`
- [ ] 使用者可在 HA UI Settings → Devices & Services → Application Credentials 新增 client_id/secret

## Technical Details
- 使用 `homeassistant.helpers.config_entry_oauth2_flow` 的 `LocalOAuth2Implementation` 或自訂 `AuthorizationServer`
- OAuth2 scopes: `smarthome:read smarthome:tunnel workspace:read`
- 支援 PKCE (code_challenge_method=S256) — 確認 HA 的 OAuth2 flow 是否自動支援
- 參考 HA core 中其他使用 application_credentials 的 integration（如 spotify, google）

## Dependencies
- 無（但實際使用時需 const.py 的 URL 常數）
