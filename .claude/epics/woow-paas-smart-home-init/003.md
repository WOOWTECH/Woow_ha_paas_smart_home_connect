# Task: API Client 實作

## Description
實作 `api_client.py`，封裝所有 woow-paas-platform REST API 呼叫。API Client 接收 `OAuth2Session` 進行認證，所有請求自動帶 Bearer Token 並支援自動 refresh。

## Acceptance Criteria
- [ ] `WoowPaasApiClient` class 接收 `OAuth2Session` 作為依賴注入
- [ ] 實作 `async get_workspaces()` → `GET /api/smarthome/workspaces`
- [ ] 實作 `async get_homes(workspace_id)` → `GET /api/smarthome/workspaces/{id}/homes`
- [ ] 實作 `async get_home(home_id)` → `GET /api/smarthome/homes/{id}`
- [ ] 實作 `async get_tunnel_token(home_id)` → `GET /api/smarthome/homes/{id}/tunnel-token`
- [ ] 實作 `async get_home_status(home_id)` → `GET /api/smarthome/homes/{id}/status`
- [ ] 所有方法包含基本錯誤處理（HTTP error → raise 對應 exception）
- [ ] tunnel_token 不出現在 debug log 中

## Technical Details
- 使用 `OAuth2Session.async_request(method, url)` 發送請求，自動帶 Authorization header
- Response 解析: JSON → dict，HTTP 4xx/5xx → raise `ApiError`
- 定義 `ApiError`, `AuthenticationError`, `NotFoundError` exception classes
- API base URL 從 const.py 取得

## Dependencies
- 依賴 `const.py` 中的 API URL 常數（可先用字串常數）
