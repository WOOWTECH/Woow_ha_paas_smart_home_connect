# Task: Component Entry Setup 與 Services 註冊

## Description
實作 `__init__.py`，在 `async_setup` 中註冊 services，在 `async_setup_entry` 中組裝 OAuth2Session、ApiClient、CloudflaredManager，並在背景啟動 tunnel。實作 `async_unload_entry` 確保進程正確清理。

## Acceptance Criteria
- [ ] `async_setup` 註冊 3 個 services: start_tunnel, stop_tunnel, get_status
- [ ] `async_setup_entry` 建立 OAuth2Session → ApiClient → CloudflaredManager，存入 `hass.data[DOMAIN][entry_id]`
- [ ] Entry setup 時在背景呼叫 `cloudflared_manager.ensure_binary()` + `start_tunnel()`
- [ ] 背景啟動失敗只記錄 warning，不阻塞 HA 啟動
- [ ] `async_unload_entry` 停止 cloudflared 進程 + 清理 hass.data
- [ ] Services 透過 entry_id 或 home_id 查找對應的 manager 執行操作
- [ ] `get_status` service 回傳 `ServiceResponse`（包含 tunnel 狀態和 home 資訊）
- [ ] Forward entry setup 到 sensor 和 binary_sensor platforms

## Technical Details
- `hass.data[DOMAIN][entry_id]` 儲存: `{"api_client": ..., "tunnel_manager": ..., "coordinator": ...}`
- Service handler 從 `call.data` 取得 home_id，查找對應的 entry
- 使用 `hass.async_create_task()` 背景啟動 tunnel（不 await）
- `async_unload_entry` 使用 `hass.config_entries.async_unload_platforms(entry, PLATFORMS)`

## Dependencies
- [003] api_client.py
- [004] config_flow.py（需要 config entry data 結構）
- [005] cloudflared_manager.py
