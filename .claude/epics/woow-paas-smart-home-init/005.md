# Task: Cloudflared Manager 實作

## Description
實作 `cloudflared_manager.py`，負責 cloudflared binary 的自動下載和進程生命週期管理。此類別職責單一，不依賴 API client 或 OAuth，只接收 tunnel_token 啟動 tunnel。

## Acceptance Criteria
- [ ] `CloudflaredManager` class 提供完整的 cloudflared 管理功能
- [ ] `async ensure_binary()` — 偵測 OS/架構，若 binary 不存在則自動下載
- [ ] `async start_tunnel(tunnel_token)` — 使用 token 啟動 cloudflared 進程
- [ ] `async stop_tunnel()` — 優雅停止 cloudflared 進程（SIGTERM → 等待 → SIGKILL）
- [ ] `is_running()` — 非阻塞檢查進程是否存活（process.poll()）
- [ ] 支援平台: Linux x86_64, Linux aarch64, macOS amd64, macOS arm64
- [ ] Binary 儲存在 HA config 目錄下 `.woow_paas_smart_home/cloudflared`
- [ ] tunnel_token 不出現在 log 中

## Technical Details
- cloudflared 啟動指令: `cloudflared tunnel run --token {tunnel_token}`
- 使用 `asyncio.create_subprocess_exec` 啟動進程
- Binary 下載源: GitHub releases (`github.com/cloudflare/cloudflared/releases/latest`)
- 下載後設定 executable permission (`chmod +x`)
- OS/架構偵測使用 `platform.system()` + `platform.machine()`
- 下載使用 `aiohttp` async streaming
